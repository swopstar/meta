# swop* meta agent instructions

Guidance for Claude Code and other coding agents working in this repository.

This repository is the source of truth for everything that applies across the
swop* suite:

- `standards/`: versioning, commit conventions and licensing.
- `adr/`: suite-wide architecture decisions (`ADR-0###`).
- `design/`: mockups shared between projects.

Anything specific to one project lives in that project's repository instead:
its overview, architecture and roadmap under `docs/`, and its own ADRs under
`docs/adr/`. Link to those rather than copying them here.
